# Reuse map: codex-tui onto rtwk

> **Superseded in part (2026-11-17, architecture.md §0, ADR-004, ADR-006;
> ../reviews/arch-review.md M7).** Top-10 #1, #4, #5, #7, #8, #9 describe the
> earlier architecture: content renderers (history_cell, markdown_render,
> diff_render, wrapping) and the Codex textarea are not carried — rtwk
> widgets replace them (composer gaps → rtwk G12); rtwk `KeyBindings` is
> used; dialogs are the model-driven modal layer. The REUSE share below
> counts those renderers. A carried row brings its dependency closure.

Generated by `reuse_map.py` from `codex-rs/tui/src` (1,268 .rs files; the port's own `frontend/` seam is excluded).
Per-file rows: `reuse-map.csv`. Rerun at every repin: `python3 -I reuse_map.py <codex-root> --rtwk <rtwk-root> --groups`.
The module table below is the script's output (rules and per-part notes live in the script, so the two cannot drift).

Categories: REUSE = unchanged. ADAPT = behaviour kept, shape changed. REPLACE = an rtwk item does the job (REPLACE+GAP where the
capability matrix says partial/missing). DROP = moot on rtwk. ORACLE = tests and snapshots, the parity suite.
`[core]` on a REUSE row = the file touches ratatui-core `Line/Span/Style` or crossterm `KeyEvent` only as data (ADR-004, ADR-006); it is reusable
unchanged while those two data crates stay in the build, and needs a type swap only if they are removed after parity.

## Top 10 decisions

1. **Content stays ratatui-core data (ADR-004).** `history_cell/`, `exec_cell/`, `status/`, `markdown*`, `diff_render`, `wrapping`, `render/highlight`
   (~27k prod lines) are REUSE [core] and feed one new `LinesView` (new code in tui-rtwk, over `rtwk-widgets` Text/Span). This is the largest
   saving; cost is one dependency on ratatui-core and a style mapping with a cell-diff test.
2. **The terminal driver is thrown away.** `custom_terminal/` DROP; `tui.rs` + `tui/` REPLACE by `run_app_with` / `ScreenMode` / `TerminalOptions`
   (frame_requester, frame_rate_limiter, screen_size, size_monitor DROP). `insert_history.rs` REPLACE by `Screen::commit` / `Static` (GAP G2/G5).
3. **State/UI separation is the main work (ADR-003).** 144k prod lines are ADAPT. Plan the new crate boundary on the three owner structs
   (`App`, `ChatWidget`, `BottomPane`+`ChatComposer`); `app_event.rs` becomes the Msg enum, `app/event_dispatch.rs` (4.6k) the reducer,
   `streaming/controller.rs` a pure reducer with effects.
4. **Textarea: ADAPT (keep Codex's editing core), not rtwk TextArea.** Codex has atomic elements (`[Image #1]`), kill ring, vim, mouse, wrap-aware
   cursor, history recall, paste-burst; rtwk TextArea lacks placeholders, vim, history recall, burst detection. Swapping breaks 1:1 key behaviour;
   rtwk `TextEditingController` is a post-parity option. Parity risk high; depends on ADR-003.
5. **wrapping.rs and markdown stay (REUSE), not rtwk text wrap / `MarkdownView`.** rtwk has no Line-level URL-preserving wrap and renders markdown
   differently (no math, mermaid, local links, table holdback). Trade-off: we keep textwrap/pulldown-cmark/unicode-width deps; a width-model mismatch
   with rtwk-unicode paint must be tested (G6 below). Streaming: keep Codex's line-based `StreamController` + chunking; `MarkdownStream::take_settled`
   settles by block and changes commit granularity.
6. **syntect stays** (`render/highlight*`, REUSE) until rtwk highlight (10 languages) and a syntect-to-`Lexer` adapter reach colour parity.
7. **Keys: keymap runtime REUSE [core]** (crossterm `KeyEvent` as the key type, ADR-006); `tui/event_stream.rs` REPLACE by rtwk-input plus a thin
   converter; the pre-filters in `app/input*` ADAPT. rtwk `KeyBindings` unused in the parity phase.
8. **Transcript: ADAPT.** `transcript_view/` keeps anchors, `LayoutCache`, selection, search, copy mode (15 of 26 files are pure logic and reuse);
   only scroll physics and viewport come from `rtwk-scroll` (`ListView(stick_to_bottom)`, `ScrollController`). Cell-accurate selection with copy-source
   mapping has no rtwk equivalent (G9). Pager (Ctrl+T) REPLACE by `LogView` once G1 exists.
9. **Bottom-pane views: state ADAPT, render REPLACE-by-LinesView, popups keep Codex rows.** rtwk `OptionList/Autocomplete/SelectionList/show_dialog`
   differ in look from Codex rows, so adopting them is post-parity; `show_dialog` is only a candidate for owned-mode modals.
10. **Two deliberate divergences for the person to approve:** `analytics/plot*, activity_chart, chart` REPLACE by `rtwk-data` charts (1.4k lines saved, cells will
    not match `plot_tests`); `pets/` + `transcript_image` image protocols REPLACE by `rtwk-rich` Image (G4: animated frames, placement while history scrolls).

DROP list (why): `custom_terminal/*` (ratatui Terminal fork; presenter does it), `tui/frame_requester`, `frame_rate_limiter` (implicit redraw, max_fps),
`tui/screen_size`, `size_monitor` (resize is an rtwk event; tmux lost-resize workaround needs a pty re-check), `rendered_selection.rs` (painted-rect
registry for immediate mode; rtwk keeps the element tree), `terminal_probe/{startup_replay,windows*}` (rtwk probes inside its input decoder).

## rtwk gaps the map adds beyond architecture.md G1-G5

- **G6 width model.** Codex wraps with `unicode-width`; rtwk paints with `rtwk-unicode` (`TextSegmenter::width`). Emoji, ZWJ, VS16 and CJK
  edge cases can mis-wrap or overflow; needs a shared-width test before LinesView is trusted.
- **G7 committed rows must carry OSC 8 links and image rows.** `Screen::commit(rows: &Surface, ..)` takes surface rows; Codex history carries hyperlink rows and
  inline images (insert_history.rs, terminal_hyperlinks). Verify links and image placements survive commit (overlaps G4).
- **G8 no way to discard pending input** (Codex `tui/input_boundary.rs` quarantines typeahead before security-sensitive prompts).
- **G9 cell-accurate selection/search/copy-source over virtualized, host-laid-out lines** (transcript_view selection, copy mode, markdown element copy);
  rtwk `SelectionArea` selects painted widget text only.
- **G10 tmux session probes** (mouse option off, pane-local graphics support) beyond `Multiplexer` wrapping.
- **G11 clipboard breadth.** `Terminal::copy_to_clipboard` emits OSC 52 `c` only; Codex also does native (arboard), WSL and X11 PRIMARY, which stay as REUSE.
- Confirmed partial (matrix) and affecting rows: Windows input (`tui/windows_*`, risk high), `$EDITOR` helper (`external_editor`), paste-burst and history
  recall (kept as REUSE/ADAPT), highlight languages, a popup growing the inline region, `DiffView` as non-scrolling history item.
- Not gaps, verified present: `PointerShape` (OSC 22), `TerminalInfo.foreground_rgb/background_rgb`, DA1/CPR probes, `Terminal::notify`, `set_title`.

## Parity-risk hot spots (high)

`tui/` driver, alt screen (G1), scrollback strategies (G5), Windows input, insert_history (G2/G7), textarea, composer state machine, BottomPane core, transcript_view,
owned transcript hosting and resize reflow (G2), image protocols, custom_terminal replacement (cell diff).
