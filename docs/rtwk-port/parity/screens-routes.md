# screens-routes — parity

S16 transcript/static pager, S18 resume/fork picker, S20 /usage dashboard, S21
agents command center, each as a view (`codex-rs/tui-rtwk/src/screens/<dir>/`)
over a UI-free core half (`codex-rs/tui-rtwk/core/src/screens/<dir>.rs`). State
comes only from JSONL fixture scripts (`fixtures/*.jsonl`) played through core
`apply`; the debug menu opens each entry. Oracle files: `tui/src/pager_overlay*`,
`resume_picker*`, `analytics/*`, `app/agents_overview*`, `app/agent_center/*`,
`bottom_pane/selection_tabs.rs`. Every number below was run:
`acargo nextest run --workspace` 182 passed (core 18 of this slice: pager 4,
resume 6, usage 4, agents 4; screens 21: pager 7, resume 7, usage 3, agents 4),
`clippy --all-targets -D warnings` and `fmt --check` clean.

## Oracle tests

13 oracle tests are ported (their snapshot rows are the expectations, the
text of the oracle's `.snap`, never our output). The other 350 tests of the oracle files are mapped
in group rows with the reason: they test ratatui models, the app-server/IO
(`session-core`), or functions of the not-ported parts (D5, D6, D8). Tests of
ours with no oracle counterpart: `pager_slot_is_registered_and_empty`,
`static_pager_scrolls_and_q_closes`, `transcript_pager_closes_with_q`,
`resume::loading_sessions_line`, `resume::no_sessions_yet_line`,
`resume::down_and_up_move_the_marker`, `usage::digit_keys_pick_the_report`,
`agents::down_moves_the_highlight_and_the_details`.

## Rules
- R14: the pager makes no `ScrollController`. A `NotificationListener<ScrollNotification>` records (offset, largest offset) into a `ValueNotifier` in the state; the rule test `rules::r14_controllers_are_made_only_in_the_allowlist` passes. Before the first move rtwk sends no notification, so the percent bar uses `estimate_max` (greedy word wrap) until the page moves; the oracle snapshots (`0%`/`100%`) pass with it.
- ADR-010: every user-visible word is in the dir's `strings.rs` (`blank` added for the empty line); layout constants are named `LEFT_PAD`, `GAP_WIDTH`, `CHROME_ROWS`, `BOTTOM_ROWS`.
- Layers: views name no protocol, shell, tokio or IO; `layers.rs`, `rules.rs` pass.
- ADR-002: every screen is `impl_widget!(stateful eq ..)`, closes through `Navigator::maybe_pop`.
- Bites shown (inject, run, restore, working tree clean after): `GAP_WIDTH` 3 to 2 fails `resume::hint_line_snapshot_uses_distributed_wide_footer`; `CHROME_ROWS` 5 to 4 fails `pager::static_overlay_wraps_long_lines` (the estimated percent).
- Red first: commit 83f5bce98 held the parity tests and core tests red before any view.

## rtwk needs
- G-new: `Scrollable` sends no initial `ScrollMetrics` notification (only after a move): a listener cannot know the largest offset of a page that has not moved. Wanted: a `ScrollMetricsNotification` on layout, as Flutter's, or a `ScrollController`-free metrics read.
- Selected-row fill (D2): a row-level background widget would remove the delta.
- `~` filler (D1): an option on `ListView`/`SingleChildScrollView` to fill unused rows with a glyph.
