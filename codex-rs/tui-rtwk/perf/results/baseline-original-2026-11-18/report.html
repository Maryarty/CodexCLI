What is compared

Same Codex core and the same kind of fake model (Codex's own MockResponsesServer, one server and one fresh CODEX_HOME per run, analytics off, no network); both run in a pty at the scenario size with TERM=xterm-256color and the driver's VT model; only the frontend differs. Everything is black box through the pty: CPU and RSS from proc_pidinfo every 100 ms and wait4 rusage, frames are DEC 2026 pairs (read bursts when absent), a key is "visible" when the VT model shows it in the screen (a DEC 2026 update held longer than 150 ms counts as visible). The VT model is a model, not a GPU terminal: byte volume is the proxy for terminal cost.
