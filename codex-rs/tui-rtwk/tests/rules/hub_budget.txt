# The hub budget (ADR-012, rules `hub_enums_only_shrink` and
# `threads_apply_matches_no_screen_or_feature_intent`, tests/rules/layers.rs).
#
# The hub's enums have one variant per case of every feature that went through them. A new
# feature is a slice (core/src/features/<f>/, the recipe at the end of ADR-012 in docs/rtwk-port/architecture.md) and adds
# no variant here: each hub component carries one generic `Feature` variant. The numbers are
# what the code has, measured the day the framework landed (the generic variants of the
# framework included); a rule fails when a count rises, and when it falls, so that a feature
# that moves into a slice writes the saving down here and it cannot come back.
#
# enum <file> <Name> <variants>
# arms <file> <fn> <pattern> <occurrences of the pattern in the function's code>
# methods <file> <Trait> <methods of the trait>

# ADR-013 (select, the page stack leaves core family by family): `Menu::Confirm` and `Menu::Review`
# are sheets of their own (`Show`/`Opening`: the one-shot the presenter shows; the pages of
# `/review` are the routes of a nested navigator). `Intent` 21 -> 25: `Confirm` (the question asked
# for), `Confirmed` (the answer Yes), `Shown` (the presenter's receipt), `Review` (the target a page
# settled on) and `ReviewList` (a list asked of the host) are added, `Instructions` goes. The
# gesture intents (`Choose`, `Secondary`, `Close`) and `Open` leave with the last family, and the
# line goes below 21 then. The worktree family follows (`Opening::Worktree`, a sheet whose pages
# are the routes of a nested navigator): `Menu` 5 -> 4, `Intent` 25 -> 26 (`Worktree`, the verbs
# `Pick`, `List` and `Abandon` a page says).
# `/apps` (adr013-select-apps) is a sheet of its own too (`Opening::Apps`; the directory and the
# link dialog are the routes of a nested navigator, `Menu::Apps` and `Picked::App` go): `Menu`
# 4 -> 3, `Intent` +2 for the verbs the sheet says that are facts for the app, `OpenAppPage` (the
# page of an app is opened in the browser) and `AppUnlinked` (an app with no page was picked: a note).
# `Menu::Quick` (`/presets`) is a sheet too (`Opening::Quick`, its pages the routes of a nested
# navigator; `Menu` 3 -> 2); `Draft` is `Preset` (what a page asks of the model).
