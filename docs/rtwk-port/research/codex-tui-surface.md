## 2. Main chat screen layout

Two renderers, chosen by `/tui` (persisted for the next launch):

1. **Inline (default).** A small viewport pinned at the bottom of the real terminal. Finalized history lines are written *above* it into native scrollback (insert_history.rs, DECSTBM scroll regions). The viewport holds the live tail (active cell) plus the bottom pane. Scrollback is a derived cache: on resize it is rebuilt from source cells (app/resize_reflow.rs, capped by resize_reflow_cap.rs).
2. **Fullscreen / "owned".** Alt screen with mouse capture. `transcript_view/` plus `app/owned_transcript.rs` render history inside the app (virtualized layout, anchors, selection, follow button, sticky prompt header, search). The fork adds a sidebar and split side panes here.

Vertical stack (chatwidget/rendering.rs): transcript area (owned mode) or live tail (inline), banners (backend_banners, InlineBanner), pending-input preview, working status indicator, composer or active BottomPaneView, footer / status line. In owned mode dialogs are centered (`DialogOverlay`, `CenteredView` in bottom_pane/view_stack.rs).

## 6. Approvals

`ApprovalOverlay` (bottom_pane/approval_overlay.rs): variants Exec, Permissions, ApplyPatch, McpElicitation. Keys: approve, approve for session, approve for prefix, deny, decline, cancel, open fullscreen view, open thread (ApprovalKeymap). Renders command with highlight, patch summary/diff, option list. ## 7. Streaming and animations

- streaming/controller.rs (2.2k): deltas to commit ticks, adaptive chunking, newline-gated commits, table holdback, code-fence handling, prose preview. Live tail cell (`StreamingAgentTailCell`) vs committed cell (`AgentMarkdownCell`, source-backed so it reflows on resize).
- Animations (all via `FrameRequester`, tui/frame_requester.rs, rate limited): spinner and shimmer, welcome, empty-state lighting, effort ignition, sparkle, split-flap, sidebar slide, pets, exec spinners, voice meter. System reduced-motion gate: system_motion.rs, motion.rs.
- Markdown: headings, lists, tables, blockquotes, task lists, local/web links, inline directives, math (14 snaps), mermaid (6 snaps), syntax highlight with themes and contrast checks.
- Diff rendering (diff_render.rs, 23 snaps): fills, line numbers, wrap, syntax-highlighted.
