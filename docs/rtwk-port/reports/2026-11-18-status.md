# tui-rtwk — состояние на 2026-11-18 (вечер)

Интеграционная ветка `claude/tui-rtwk` (не пушится). Оракул — официальный codex 0.170.0
(`~/.cache/codexcli/oracle-bin/codex`), rtwk-пин 9f28b7fb (переезд на e3debfda — следующий шаг).

## 1. VS1 — Agent command center (`codex-rtwk agents`)

**Статус:** влит (714c3e32a), хвосты `vs1-followups` на проверке перед вливанием (e40233264).
Попробовать: `~/.cache/codexcli/try/codex-rtwk agents` (оригинал: `~/.cache/codexcli/oracle-bin/codex agents`).

Что работает: реальные сессии с app-server, все источники, группировка (в т.ч. по проекту/каталогу
через shell), фильтры-вкладки, поиск с debounce 180 мс, детали, usage, действия
(new/stop/pin/rename/archive/delete/fork/worktree) с окнами подтверждения и ошибок, переход в чат
и обратно с сохранённым выбором, мышь (клик, двойной клик, колесо), цвета сессий из темы,
`--help`/`--version`.

Паритет: pty-сценарий `codex agents` совпадает с бинарём оригинала на всех контрольных точках;
экранные тесты по снимкам оригинала зелёные, 7 — `pending` с владельцами
(keymap ×3, reuse-carry ×2 Markdown-превью, rtwk G35 ×2).

**Не закрыто (до гейта VS1):**
- Ревью Opus — вердикт FIX: 5 дефектов, 14 should-fix, 17 заметок
  (`docs/rtwk-port/reviews/vs1-review.md`). Главное: закрепление переключается вместо установки;
  курсор в двух местах (ядро + SelectionController) → `jj`/клик открывают не ту сессию; глубокое
  копирование состояния на каждую дельту; падение на ширине ≤ 8; утечка тикета в поиске.
  → задачи `agents-core-fix` (ядро/shell) и `agents-view-rtwk` (экран).
- Экран написан во многом НЕ штатными средствами rtwk (ручные wrap/ellipsize/колонки/области,
  построчные диалоги) → `agents-view-rtwk`: пересборка на Text/TextOverflow, Row/Column/Expanded,
  Table, show_dialog/Dialog::bare, Divider + правило-тест против ручной раскладки.
- Первый кадр медленнее оригинала → `perf-first-frame`.

## 5. Почему агенты писали не штатными средствами (разбор по транскриптам)

1. Правило «сначала rtwk» было влито в основную ветку, но не в ветку портеров agents-live
   (мой промах); там лежало старое исследование, прямо велевшее не использовать обрезку rtwk.
   7 из 11 механизмов прописаны заданием/исследованием, 5 скопированы с влитых экранов.
2. Стимулы: «ни одного отличия» + тесты до клетки, а настоящий пробел rtwk нельзя было сдать.
3. Справочник почти не читали; вывод «TabBar не годится» сделан чтением исходника без прогона;
   ручной перенос оказался дальше от оригинала, чем `TextWrap::Word` rtwk (17 vs 10 из 45).

**Исправлено в процессе сегодня:**
- `process.md` §5, fleet-brief, описания портера/ревьюера: «поведение оригинала, а не его механика;
  сначала виджет/контроллер rtwk»; не копировать влитые экраны — образец справочник и галерея rtwk;
  «rtwk не может» — только после прогона; документы и скилл читаются из основной копии по
  абсолютному пути.
- Правило пробелов (ваше): подтверждённый прогоном пробел → строка в `rtwk-gaps.md` +
  тест `pending(Gxx)`, задача сдаётся, без обходов; я сообщаю вам, вы решаете, идёт ли в rtwk.
- Скилл rtwk перестроен по образцу twk (Flutter-рамка, отличия, приложение, тест, ловушки,
  справочник + таблица ratatui → rtwk); `--check` ловит несуществующие имена API.
  Оркестратор rtwk берёт из него проверку имён, to-do-сниппет и инструкцию по галерее.
- Проход по всем задачам/исследованиям: 6 заданий поправлены, 9 мест исследований помечены
  отменёнными, 11 групп ручной механики во влитом коде разведены по задачам
  (`docs/rtwk-port/reviews/rtwk-first-sweep.md`).

## 6. Пробелы rtwk для вас (подтверждены прогоном или кодом)

- `TextOverflow::Ellipsis` выкидывает пробелы перед `…` (оригинал оставляет).
- `EllipsisStart` режет иначе, чем оригинал.
- G36 `TabBar`: нет незаполненного промежутка между вкладками, крайние метки поверх вкладок,
  прокрутка по колонкам.
- G35 `SelectionList` прячет `ListController`: нет листания/перехода с конца на начало,
  заголовка над первой задачей, прокрутки при внешнем сдвиге курсора.
- `ThemeData` без слота расширений (как `ThemeExtension` во Flutter) — палитра сессий живёт
  рядом с темой.
- (под вопросом) перенос после `/`.
Закрыто в rtwk main e3debfda: G2, G13, G14, G27 + EditingKeys, Dialog::bare, pump_app_in,
inline-ссылки/картинки, каталог API и собственный скилл rtwk.
