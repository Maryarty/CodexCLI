#
# Today's violations of the boundary rules, by key and count. A rule fails when a count rises (a
# new violation: new code cannot add to this list) and when it falls (the saving is written down
# here, so it cannot come back); a line at 0 is deleted. The numbers only go down, as
# hub_budget.txt's do. A family leaves its lines when its migration step lands (full §15):
#   step 2  select::Menu families (models, permissions, review, worktree, apps, quick dials,
#           collaboration, export), the picker's list vocabulary (`select/list.rs`, `layout.rs`)
#           moves to widgets/picker, `stack`/`kept` to a SheetStack, `Picked` to verbs;
#   step 3  settings, dialogs, resume (`density`, `expanded`, `Cursor/Room/End`), pets, agents;
#           /goal, /export, /rename put their menus and prompts in the UI half;
#   Feature's Menu/Pick/Prompt and FeatureView's hooks go with the pilot's `Feature` without UI forms.
# A rule with no line here holds today in full: the rules about `Interest`, `Directive`,
# `SurfaceWish`, `Sheet` and `thread_scope` bite the day their mechanism lands.
#
#   ratchet <rule> <key> <count>      today's count of the key (a file, or file:Type.field)
#   exempt  <rule> <key> <why...>     a named exception, not counted
